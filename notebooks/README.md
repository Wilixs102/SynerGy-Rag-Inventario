# Análisis reproducible

No se requiere un notebook para ejecutar el prototipo. El análisis se mantiene en scripts versionados para evitar estado oculto:

- `scripts/analizar_resultados.py`: análisis del conjunto histórico de 270 generaciones.
- `scripts/resumir_consolidacion.py`: resumen de las nueve generaciones actuales y aplicación del criterio que admite COLLATE.
- `scripts/recopilar-evidencias.ps1`: pruebas y verificaciones funcionales seleccionadas.

Consulte el README principal para instalar dependencias y ejecutar las pruebas. No añada aquí exportaciones del inventario real.
